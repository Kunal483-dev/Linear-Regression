# House Price Prediction Using Linear Regression

This project implements Simple Linear Regression and Multiple Linear Regression to predict house prices using the Housing dataset.

## Objective

- Understand Simple Linear Regression
- Understand Multiple Linear Regression
- Train a model using Scikit-learn
- Evaluate models using MAE, MSE, and R² Score
- Visualize predicted and actual house prices

Dataset file: `Housing.csv`
